# Interview Prep Research Sources

The role-specific practice questions are original scenarios inferred from the role competencies and interview guidance below. They are not presented as verbatim questions from a particular employer. Sources were accessed September 2, 2026.

## Interview format and answer guidance

- [Microsoft Careers — Technical interviewing](https://careers.microsoft.com/v2/global/en/hiring-tips/technical-interviewing.html): problem solving, coding, design, testing, data structures, system design, and explaining choices.
- [Microsoft Careers — Interview tips](https://careers.microsoft.com/v2/global/en/hiring-tips/interview-tips.html): clarifying questions, stating assumptions, explaining choices, and the STAR(R) framework.
- [Amazon Jobs — University SDE online assessment prep](https://www.amazon.jobs/content/de/how-we-hire/university-roles/sde): confirms that student and graduate interviews assess technical proficiency and behavioral skills.

## Role-specific foundations

- **Software / Application Developer:** [MDN JavaScript fundamentals](https://developer.mozilla.org/en-US/curriculum/core/javascript-fundamentals/) and [Microsoft technical interviewing](https://careers.microsoft.com/v2/global/en/hiring-tips/technical-interviewing.html).
- **Business / Systems Analyst:** [IIBA Business Analysis Standard](https://www.iiba.org/knowledgehub/the-business-analysis-standard/) and [IIBA requirements and designs](https://www.iiba.org/knowledgehub/the-business-analysis-standard/4-implementing-business-analysis/4-4-understanding-requirements-and-designs/).
- **Data Analyst / Data Scientist:** [Microsoft Power BI Data Analyst certification](https://learn.microsoft.com/en-us/credentials/certifications/data-analyst-associate/) and [Microsoft data analyst career path](https://learn.microsoft.com/en-us/training/career-paths/data-analyst).
- **Cybersecurity Analyst:** [NIST incident-response recommendations](https://csrc.nist.gov/pubs/ir/8428/final) and [NIST NICE Workforce Framework](https://www.nist.gov/itl/applied-cybersecurity/nice/nice-framework-resource-center).
- **IT Project Manager:** [PMI project manager responsibilities](https://www.pmi.org/about/what-is-a-project-manager) and [PMI Project Management Basics](https://www.pmi.org/certifications/~/link.aspx?_id=FF99743C71A271367017995CAEBDD95A&_z=z).
- **UX Designer / Product Manager:** [Nielsen Norman Group UX Careers report](https://media.nngroup.com/media/reports/free/UserExperienceCareers_2nd_Edition.pdf), including its discussion of portfolios, practical exercises, research, prototyping, and usability testing.
- **ERP / Systems Consultant:** [SAP Cloud ERP implementation and operations learning journey](https://learning.sap.com/learning-journeys/exploring-end-to-end-implementation-operations-sap-cloud-erp-professional-services) and [SAP S/4HANA implementation configuration](https://learning.sap.com/courses/implementing-sap-s-4hana-cloud-private-edition/defining-business-process-configurations-for-new-implementations_d6ff60c0-095d-4b72-93e9-a78a85c8f003).
- **Cloud / Infrastructure Engineer:** [AWS Cloud Practitioner exam guide](https://docs.aws.amazon.com/aws-certification/latest/cloud-practitioner-02/cloud-practitioner-02.html) and [AWS certification exam guides](https://docs.aws.amazon.com/aws-certification/latest/examguides/aws-certification-exam-guides.html).

## Feedback limitation

The prototype uses transparent concept matching and answer-structure signals. It does not use a language model and should be described as practice feedback, not as an authoritative judgment of an applicant or a hiring prediction.
